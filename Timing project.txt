GOAL:
Create a Windows desktop overlay that helps my little brother perform the jump at the correct time.

HOW IT SHOULD WORK:

In the referenced section, the player uses a shrinking/size mechanic before a jump.
When the shrinking/size event happens, the assistant should start its timing sequence.
The assistant should calculate/show the best moment to press the jump key.
It should clearly tell the player when to wait and when to jump.
The main purpose is to reproduce the timing assistance shown in the video, NOT simply make a generic stopwatch.
OVERLAY:

Small, clean Windows overlay.
Always-on-top.
Can be moved anywhere on the screen.
Can be resized.
Should not cover much of the game.
Very clear text indicating the current timing state.
Example states:
WAIT before 3500 ms
JUMP from 3500 ms through 4700 ms
TOO LATE after 4700 ms

KEYBOARD DISPLAY:

Show the relevant keyboard keys visually.
Highlight the JUMP key when it is time to press it.
Show the timing of the detected/input event if possible.
Allow the jump key to be changed in settings.
TIMING:

Timing must be configurable.
Include milliseconds precision.
Include a calibration mode.
Allow us to adjust the delay between the shrinking/size event and the recommended jump.
Save the calibration settings so they remain after restarting the program.
CONTROLS:

Hotkey to enable/disable the overlay.
Hotkey to start/reset the timing sequence.
Hotkey to enter calibration mode.
Configurable jump key.
Configurable activation/reset keys.
